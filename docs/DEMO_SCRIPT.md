# Five-minute demo script

Assumes the API and Expo are running, and you have created the local owner passphrase.

1. **Sign in** (10 s). Point out that no default password exists and the session is backend-validated.
2. **Overview → Priya "Lyra" Nair** (40 s). Read the next-step card: *Priority Review · cardiovascular*.
   Note the completeness line ("N of M relevant fields"), the stale/missing labels and the stream banner.
3. **Open Cardiovascular** (50 s). Walk the hierarchy: category → headline → facts → evidence with units,
   time and context → gaps → rule id `CV-*` and assumptions → prevention with reasons. Say explicitly:
   "There is no probability and no clearance here."
4. **Reported vision changes for Kenji "Kite" Watanabe** (40 s). Same engine, different rule ids, with the
   distinction between "no vision change reported" and unanswered.
5. **Guided check** (60 s). Press *Start useful check*, read *Why this check?*, enter a value, save. The
   confirmation shows the before/after category; the case timeline now has a dated event.
6. **Simulator** (70 s). Choose Diego "Tomo" and *sleep deprivation*, preview the intended changes, generate
   a run, then replay day 1 → 7 and compare baseline vs scenario. Apply the stream: every screen is now
   labelled simulated. Return to baseline.
7. **Deep Space Link** (60 s). Create a handover from the vision case, show the frozen snapshot, queue it,
   advance the clock to delivery, compose the fictional ground reply, then advance again so it arrives.
   Emphasise: delivery ≠ reviewed, treated or cleared; nothing left the device.
8. **Data integration** (40 s). Load the valid example, show suggested mapping, validation counts, preview,
   commit. Then load the invalid example and show row/column/expected messages and the downloadable report.

Close on the honest limits: software only, fictional data, illustrative thresholds, no prediction, no
clearance, not certified for real medical records.
