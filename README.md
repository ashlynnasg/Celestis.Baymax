🚀 Celestial Baymax

Predict. Prevent. Protect. Recover.

Celestial Baymax is an astronaut-health monitoring prototype developed for the NASA Space Apps Challenge 2026.

It connects astronaut medical history, health monitoring, explainable screening, guided follow-up and mission review into one application.

Using fictional astronaut profiles and simulated or manually entered observations, it demonstrates how crew health information can be monitored and communicated during long-duration space missions, even when communication with Earth is delayed.


🌌 The Problem

During extended space missions, astronauts may experience changes in their physical and mental health. Identifying these changes is only the first step. Understanding the risks, performing follow-up checks and communicating findings to medical teams are equally important.

Celestial Baymax explores how software can connect these processes into one continuous health-monitoring workflow.

💡 Key Features

1. Astronaut Profiles & Health Monitoring

- Six fictional astronaut profiles with different medical histories.
- Create, edit, search, archive and restore profiles.
- Monitor heart rate, oxygen saturation, sleep, stress, fatigue and exercise.
- View health trends, timestamps and missing or outdated observations.

2. Explainable Health Screening

Screens eight health domains:

- Cardiovascular health
- Bone health
- Muscle health
- Sleep
- Fatigue
- Vision
- Stress
- Respiratory health

Provides supporting observations, relevant history, uncertainty and suggested follow-up.

3. Guided Follow-Up & Health Assistant

- Guided checks for missing health information.
- Conversational assistant using predefined local explanation logic.
- Continuing health case timelines.

4. Mission Review

- Configure mission destination, duration, activities, workload and EVA requirements.
- Prioritize crew reviews using four categories: Priority Review, Review Before Assignment, More Data Needed and No Demo Flags.

5. Deep Space Link Simulation

- Simulates communication delays and link outages.
- Queued health handovers and fictional ground-team replies.
- Preserves evidence snapshots and continuing case updates.

6. Mission & Radiation Context

- Records mission conditions, radiation observations and cabin information.
- Preserves original measurement units and distinguishes absorbed dose from dose equivalent.

7. Demonstration Scenarios & Data Import

- Six scenarios covering normal observations, sleep deprivation, cardiovascular strain, vision changes, reduced exercise and recovery.
- CSV/JSON importing with validation and error reporting.

⭐ What Makes It Different?

Celestial Baymax focuses on continuity between health evidence and action.

It connects the original observation, screening result, missing information, follow-up checks and medical handover instead of treating health alerts as isolated events.


🖥️ How to Run the Application (Windows)8

Follow these steps to run Celestial Baymax locally.

Step 1: Download

Download the project ZIP file from the provided project link.

Step 2: Extract

Extract the ZIP file into a folder on your computer.

Step 3: Setup

Double-click "setup_windows.cmd".

A terminal will open and download the required dependencies. Wait until it displays "Press any key to continue...", then press any key.

Step 4: Start the Application

Double-click "start_windows.cmd".

Wait for the application to load. It should automatically open in your default web browser.

Step 5: Sign In

Sign in using the available local owner access.

That's it! You can now explore Celestial Baymax.

Note: Keep the terminal window open while using the application.
